# Day 07 - React Mini Project

This is my final project in my 7-day React learning journey.

## Mini Project: Task Manager

A simple task management application built using React.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter all, active, and completed tasks
- Display task statistics
- Save tasks automatically in localStorage 
- Keep tasks after refreshing the page
